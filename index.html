GZ-Diplomacy Bug Report

Thanks for testing GZ-Diplomacy. This form is for bugs related to team creation, prepared starts, joining/leaving teams, diplomacy stances, admin tools, debug output, or multiplayer behavior.

Best reports are short and specific. Tell me what button you clicked, what happened, what you expected, and paste any relevant GZ-Diplomacy/Gizmod debug output if you have it.

Crash or desync? Please include factorio-current.log and the relevant file from Factorio/script-output/GIZMOD_logs/ if available.

Team / force context

Logs
